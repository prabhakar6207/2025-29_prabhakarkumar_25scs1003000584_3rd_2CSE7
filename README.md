# 📧 Spam Email Classifier

A Machine Learning project that classifies email messages as **Spam** or **Not Spam**.

## 🚀 Features

- Enter an email message
- Detect whether the email is Spam or Not Spam
- Shows spam probability
- Simple Streamlit web interface

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Pickle

## 📂 Project Files

- `app.py` – Main Streamlit application
- `train_model.py` – Trains the Machine Learning model
- `dataset.csv` – Email dataset
- `spam_model.pkl` – Saved trained model
- `requirements.txt` – Required Python libraries
